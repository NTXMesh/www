Repeater IDs

How Repeater IDs Work

Every MeshCore repeater is identified by a single byte — a two-character hex value from 00 to FF, for 256 possible IDs. To keep the North Texas mesh healthy, each deployed repeater should claim a unique ID. The status of every ID falls into one of the categories below.

Available
Unclaimed and free to use. Generate a private/public key pair to deploy a repeater on this ID.
Deployed
Already claimed by an active repeater. See the live map below for the name, location, and last-heard time.
Duplicate / Conflict
More than one repeater is using this ID. Resolve the conflict by changing one repeater's public/private keys.
Reserved
Not available by design (for example, 00 and FF). Do not deploy on a reserved ID.

Deploying a repeater? Pick an Available ID, then generate a key pair with the MeshCore Key Generator. The generator's source is published so you can verify it or run it yourself.

Before deploying, coordinate with the community on the NTX Mesh Discord to avoid ID conflicts and confirm current MeshCore settings.
